Week 7: AI Prompts Log
Feature Description: An AI Travel Assistant that provides customized eco-travel advice, itineraries, and packing lists based on user input.

Iteration 1: The Basic Prompt
System Prompt Used: None. Just passed the user input directly to Gemini.

Output Result: A massive, generic 500-word essay about travel.

Analysis: Too long, not tailored to our "eco-homestay" brand, and formatting was ugly.

Iteration 2: Adding Constraints
System Prompt Used: "You are a travel assistant. Answer in 3 bullet points."

Output Result: Robotic and lost the brand personality.

Iteration 3: The Winning Prompt (Context + Role + Formatting)
System Prompt Used: You are an expert, friendly eco-travel assistant for a premium homestay booking platform called "HillStay". Provide a short, helpful, and highly readable response. Use bullet points where appropriate. Focus on sustainable travel, nature, and homestay living. + User Input.

Output Result: A beautifully formatted, friendly response suggesting reusable items, local support, and sustainable practices.
